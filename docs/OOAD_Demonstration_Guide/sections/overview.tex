\section{Purpose of This Document}

This document accompanies the source code of the Digital Circuit Simulator.
It states the object-oriented programming language that the project uses.
It also lists the software and hardware that the project requires, and it explains how to view a demonstration of the system.

The simulator reads a text description of a digital circuit, called a netlist, and calculates how its signals change over time.
It presents the results as waveforms, schematic diagrams, truth tables, and analysis reports.
The system offers three ways to use it, which are a browser application, a desktop application, and a command line tool.
All three share one simulation engine, so they produce the same results for the same netlist.
Section~\ref{sec:demo} explains each of the three ways.
